# مغز دوم

اینجا «مغز دوم» من است — حافظه دائمی دستیار برای پروژه **AmberGram**.
هر ایده، هر نکته فنی، هر خطا و راه‌حل و هر تصمیمی اینجا ثبت می‌شود تا هیچ‌چیز فراموش نشود؛ حتی اگر محیط کاری (سندباکس) ریست شود، چون این پوشه داخل ریپازیتوری است و به GitHub پوش می‌شود.

## ساختار فایل‌ها
| فایل | محتوا |
|---|---|
| `STATE.md` | وضعیت فعلی پروژه: نسخه‌ها، قابلیت‌های انجام‌شده، کارهای صف‌شده، رویه انتشار |
| `IDEAS.md` | بک‌لاگ ایده‌ها و قابلیت‌های آینده (از رقبا + ایده‌های اختصاصی) |
| `LESSONS.md` | نکته‌برداری فنی: خطاها، راه‌حل‌ها و درس‌ها |
| `LOG.md` | گزارش نوبت‌به‌نوبت: خلاصه افکار و تصمیم‌های هر جلسه کاری |

## قواعد ثابت (برای من — دستیار)
1. در پایان هر نوبت کاری، بخش جدیدی به `LOG.md` اضافه کن.
2. هر ایده‌ای که در گفتگو مطرح می‌شود → `IDEAS.md`.
3. هر خطا و راه‌حل → `LESSONS.md`.
4. هر تغییر وضعیت (نسخه جدید، انتشار، کار تمام‌شده) → `STATE.md`.
5. بعد از هر تغییر، کامیت و پوش به `master` (پوش معمولی امن است؛ CI فقط با تگ `v*` اجرا می‌شود).
6. پاسخ به کاربر همیشه به فارسی است.
